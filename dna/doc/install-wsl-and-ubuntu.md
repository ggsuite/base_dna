# Install WSL and Ubuntu

## Install WSL

Press `Windows`

Type `wsl` and press `Enter`

Press a button to install WSL

## Install Ubuntu

Press `Windows`

Type `powershell` and press `Enter`

Get a list of available Ubuntu installations:

```bash
wsl --list --online
```

Install one of them:

```bash
wsl --install Ubuntu-22.04
```

Enter a username of your choice

Enter and remember a password

## Start Ubuntu

Press `Windows`

Type `wsl` and press `Enter`

The Ubuntu image is started automatically
